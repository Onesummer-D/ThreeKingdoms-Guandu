- FR-054：首页三个主入口等尺寸横排；设置改为齿轮入口，并提供独立的全局静音图标。旧的右侧音量条移除。设置字号适合 1920×1080 阅读，画质档与全屏状态必须给出可感知或可解释的反馈。

## 范围

本增量延续已由用户确认的阶段三方向：把资源状态转成可感知的响应式影像反馈，并让剧情回顾完整反映玩家已经走过的关键片段。

阶段三已完成并通过实机验收。阶段四在不破坏现有单人路线和离线 Windows 运行的前提下，新增“邀约式”共创 MVP：玩家可以把当前战局包装为一张军议邀请，邀请另一位参与者在同一设备或同一构建中提出策略建议，并将双方贡献汇总为可回看的“共谋回声”。该机制先做可录屏、可复现的本地闭环，不把联网服务作为前置依赖。

- **FR-032**：返回主菜单时，剧情回顾入口不可见；开始新一局后入口恢复。
- **FR-033**：资源变化在画面上产生明显但短暂的色彩/闪变反馈，且不遮挡主要 UI。
- **FR-034**：抵达任一结局后，终局界面提供独立的“本局复盘”入口；普通剧情回顾入口在终局界面隐藏，返回主菜单后两个入口均不可见，开始新局后普通入口恢复。
- **FR-035**：本局复盘按已完成章节展示玩家在各决策锚点的实际选择、代表性剧情片段、结局卡片和结局图片，不泄露未到达章节的内容。
- **FR-036**：七条结局线各自拥有不同的总体评价文案；评价只在对应结局已抵达后显示，并与结局卡连续呈现。
- **FR-037**：五个已访问的剧情决策锚点均提供“史官注”入口；每条史官注包含史书记载、白话释义、游戏改编说明和来源字段。
- **FR-038**：史官注以独立弹层呈现，可从普通剧情回顾或终局复盘打开并关闭，不改变剧情进度和已访问节点。
- **FR-039**：3C 回归检查覆盖普通回顾、终局复盘、关闭复盘、返回主菜单和重新开始，确认入口生命周期与未访问内容收口。
- **NFR-031**：不修改剧情节点、资源数值或 ScriptableObject 数据结构；代码可在离线 Windows Unity 环境运行。
- **NFR-032**：终局复盘入口复用现有“返回主菜单”按钮的视觉资源与交互反馈，不引入新的场景资源依赖。
- **NFR-033**：史官注首批内容以内置运行时文本提供，不新增外部素材或网络依赖；弹层不遮挡主回顾状态的恢复逻辑。
- **FR-040**：玩家在已访问的关键决策锚点或终局复盘中可以打开“军议邀约”，生成包含当前幕次、已选路线和关键资源状态的邀请快照。
- **FR-041**：邀请快照生成短邀请码和可读邀请卡；邀请码可复制到系统剪贴板，邀请卡在 1920×1080 下可直接录屏展示。
- **FR-042**：另一位参与者可在同一构建的“应邀加入”入口输入邀请码，查看快照并提交一次策略建议；无效码、取消和返回都不改变主玩家路线。
- **FR-043**：主玩家可确认或拒绝应邀建议；确认后生成带“主将选择/应邀谋士”署名的“共谋回声”卡片，并在本局复盘中显示一段由双方贡献共同决定的衍生叙事评价。
- **FR-044**：邀约流程支持重新邀请、取消和关闭；它不要求联网，不阻塞原有单人剧情，重新开始时清理本局邀约状态。
- **FR-045**：邀约卡和共谋回声沿用现有官渡视觉语言，提供明确的参与者身份、当前战局和下一步提议，避免退化成单纯分享按钮。
- **FR-046**：阶段四回归检查覆盖创建邀请、有效加入、无效邀请码、确认/拒绝、关闭返回、终局复盘和重新开始，确保主线与邀约状态隔离。
- **NFR-034**：邀约式 MVP 在离线 Windows Unity 环境可完整演示，不引入后端、账号或第三方网络服务依赖。
- **NFR-035**：邀约过程只写入运行时会话状态，不修改对白节点、资源数值、ScriptableObject 或原始剧情路线。
- **NFR-036**：邀约 UI 与状态组件可复用于五个决策锚点和终局复盘，邀请码解析与共谋结果生成保持确定性，便于录屏复现和后续扩展。

## 验收

1. 访问 500215 后打开回顾，可看到彩蛋图片与一行摘要。
2. 点击返回主菜单后，入口隐藏；再次开始游戏后入口出现。
3. 触发资源增减，约 2 秒内可看到对应色彩闪变和数字脉冲；回顾、对白和选项仍可读。
4. 到达五个决策锚点后，章节卡出现“史官注”；弹层可查看四层信息并关闭回到回顾。
5. 终局复盘和主菜单流程按 3C 清单跑通，未访问章节、旧局入口和旧局选择不会泄露到新局。

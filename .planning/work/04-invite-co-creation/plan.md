## 设计约束

- 入口复用现有剧情回顾/终局复盘的视觉语言和 TMP 字体；不新增网络、账号或后端依赖。
- 后续手机服务可使用房间码；当前不生成无法校验的本地邀请码。
- 应邀者的建议先进入待确认态，主玩家确认后才生成共谋回声；拒绝、关闭、返回和重新开始都可清理会话。
- 共谋回声是对本局路线的衍生叙事/评价层，不回写对白节点，不改变既有七条结局判定。
- 同一套组件可挂接五个决策锚点及终局复盘，避免为每一幕复制一套不可复用 UI。

## 验收标准

1. 在任一实时决策锚点能够生成含已走剧情、问题、路线与资源上限的邀请快照和邀请卡。
2. 使用正确邀请码进入后，能看到幕次、已选路线、关键资源和邀请方署名；错误码有明确提示且不改剧情。
3. 应邀者提交建议后，主玩家可以确认或拒绝；两种结果均有可见反馈。
4. 确认后生成“主将选择 / 应邀谋士建议”的共谋回声卡，并能在回顾中再次查看。
5. 关闭、返回主菜单、重新开始后邀约状态按预期清理；普通单人路线仍可独立完成。
6. 阶段四流程可在离线 Windows Unity 环境复现，并可录制为全国赛“邀约式”展示片段。

# 4C 参谋建议闭环

Status: awaiting_visual_verification
Active Task: 05-regression-qa

## 目标

在不引入网络、账号或服务器的前提下，把军议邀约从“复制提示文字”推进为可回归的本机离线闭环：主将发起邀约，参谋填写一次建议，主将查看并采纳或拒绝；采纳只记录为建议回声，不替玩家自动点击选项，也不重复结算资源或结局。

## 范围与约束

- 仅支持当前运行实例的本机接力演示，界面必须明确离线语义。
- 邀约绑定当前运行、节点和状态版本；新局、读档、返回主菜单、取消或关闭时清空旧会话。
- 单人路径保持原样，邀请流程不得阻塞主线或自动推进剧情。
- 不改动对话 ScriptableObject、资源结算和结局判定逻辑。

## 任务拆分

- [x] 01-runtime-session：实现会话状态、状态流转、运行/节点绑定与重置。
- [x] 02-guest-submit：增加本机接力入口、邀请码校验、选项选择、理由输入及一次性提交。
- [x] 03-host-review：增加主将查看建议、采纳/拒绝/撤销，并防止重复操作。
- [x] 04-echo-history：把采纳结果写入回顾/战绩报告，不影响实际决策。
- [ ] 05-regression-qa：静态契约、编译、Unity 关键路径与各剧情线回归。

## 验收标准

1. 未发起邀约时，原有军议邀约按钮和单人决策可用。
2. 有效本机接力码可进入建议界面；无效码、关闭、取消不改变当前节点。
3. 参谋只能提交一次选项和理由；主将可采纳、拒绝或撤销，按钮状态与提示一致。
4. 采纳后出现“共谋回声”记录，但玩家仍需亲自点击原选项；资源/结局只结算一次。
5. 新局、读档、返回主菜单后不存在旧邀约或旧建议。
6. `Documentation/QA/VerifyPhase4.ps1` 通过，并完成 Unity Play Mode 关键节点烟测。

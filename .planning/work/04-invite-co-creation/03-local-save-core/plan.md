# 4A 第二批任务一 · 本地存档核心

Status: in_progress
Active Subtask: 01-safe-snapshot

## 目标

建立离线 Windows 可用的版本化 JSON 存档。先确保“存得完整、读档不重复扣资源、损坏档不破坏原文件”，再接可见首页槽位界面。

## 步骤

1. [x] 定义版本化存档数据：当前安全节点、访问顺序、锚点选择、四项资源、IF/结局标识、保存时间与槽位标题。
2. [x] 为 `DialogueSystem`、`ResourceManager`、`CampaignMapUI` 增加只读导出和受控恢复入口。
3. [x] 实现 `LocalSaveManager`：三个手动槽、一个自动检查点、临时文件写入、备份和损坏提示。
4. [x] 在安全剧情节点自动更新检查点，结局节点生成“通关结局 X：名称”归档标题。
5. [x] 接入最小可见入口：首页“查看存档”，局内“保存进度”，支持读取、覆盖提示和空槽状态。
6. [ ] 添加纯逻辑回归，覆盖往返序列化、损坏 JSON、槽位隔离、选择恢复与重复读档不叠加资源。

## 边界

- 不保存小游戏进行到一半的帧状态；此时只保留最近安全检查点。
- 不修改对白 ScriptableObject，不调用选项处理函数恢复资源。
- 首批只做本机文件，不做账号、云存档或跨设备同步。
- 自动档不覆盖三个手动槽；损坏文件保留并显示原因。

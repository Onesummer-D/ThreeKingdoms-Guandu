# 4B · 战绩日志、报告与本地海报

Status: in_progress
Active Subtask: 03-png-export

## 目标

用同一份真实本局日志生成终局战绩报告和本地 PNG 海报。报告只总结玩家实际走过的路线，不复制结局判定，不制造排名、胜率或人格诊断。

## 子任务

1. [x] `01-run-history`：记录有效游玩时长、已显示节点、实际选项、选项前后资源和变化原因，并进入存档。
2. [x] `02-report-ui`：终局新增“战绩报告”，显示结局、路线、可解释倾向、决策证据、四资源趋势、文化说明和参谋记录占位。（待实机视觉）
3. [x] `03-png-export`：将当前报告导出为真实 PNG，保存到本机图片目录，失败时回退到持久化目录。（待实机打开文件）
4. [x] 加入编译、日志一致性、七结局评价和报告字段自动检查。
5. [ ] Unity 实机用至少一条完整路线验收报告、图表和 PNG 文件。

## 约束

- 只记录已经实际执行的选择和资源状态；读档恢复日志但不重复追加同一选择。
- 趋势图的数据点必须能追溯到节点/选择，不以最终四项资源伪装成统计。
- 玩家画像命名为“本局决策倾向”，必须展示实际选择证据。
- 首版分享仅保存 PNG，不自动发布、不带设备路径/账号信息、不生成二维码。
- 4C 未完成前，参谋区明确显示本局无已确认参谋记录，不伪造参与者。

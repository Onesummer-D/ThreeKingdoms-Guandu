其他调整：

- 顶部“官渡之战 · 军议邀约”从原 `clamp(26px,6.9vw,36px)` 改为 `clamp(32px,8.2vw,45px)`，整体上移；删掉“军前问策 · 共谋此局”副标题。
- 删除底部“本次军议仅接收一份有效建议；提交不代表主将采纳。”常驻提示。**只接收一份**是后端现有业务规则，仍保留；提交成功只表示建议已送达，不冒称主将采纳。
- 服务端静态路由白名单已为六张图增加正确 `image/webp` MIME。未更改 POST 建议接口的字段或 Unity 调用方式。
- 视觉素材没有放进 Unity `Assets`，因为玩家扫码访问的是单独的 Node/H5 服务。发布时需更新 `server/public-advisor` 的云端版本。

实机待验收：手机宽 360/390/430 CSS px；长篇剧情是否卷轴拉伸正常，三列选项文字是否被卷纹遮挡，输入中文/换行、倒计时、提交反馈，以及刷新已提交/过期邀约的禁用状态。

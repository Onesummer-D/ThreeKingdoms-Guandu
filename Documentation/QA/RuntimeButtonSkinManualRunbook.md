# 国风按钮 UI 统一方案与手动验收

基准：图四「资源趋势详情」右上角「关闭」按钮同源的主菜单 StartButton Sprite。新增 GameButtonSkin.cs，统一使用原有装饰底图、描边、鼠标悬停与按下态。支持原生 9-Sliced（仅在边框确实存在时启用）。

## 五种操作语义

| 样式 | 按钮举例 | 视觉目的 |
|---|---|---|
| Primary 棕金 | 采纳建议、保存、确定、复制邀请、分享海报 | 主要操作 |
| Highlight 亮铜+强金边 | 史官卡片、问史官 | 突出容易忽略的入口 |
| Secondary 木褐 | 其它普通操作 | 一般功能 |
| Quiet 灰棕 | 关闭、返回、撤销邀约、复制路径 | 次要或撤回操作 |
| Caution 暗砖红 | 拒绝建议、直接退出 | 带否定/退出含义的操作 |

## 覆盖范围

- 军议邀约与主将审核三个并列操作、关闭、再邀参谋、出征前提示；
- 战役回顾、史官卡片按钮、史官注、史官卡片列表、问史官；
- 战绩报告、资源趋势详情、海报导出后四个并列操作；
- 游戏设置、关于、存档保存/加载、战役回放、退出确认；
- AI 史官聊天关闭、发送、快捷提问和引用详情按钮。

不把整个可点击的剧情卡片、列表行、已有贴图的原生场景剧情选项或图标型操作强行替换为小按钮背景，避免破坏布局与语义。

## Unity 验收清单

1. 打开剧情回顾，史官卡片按钮应清晰可见，带暖铜底和更强金色描边，右侧关闭则深灰棕。两者无重叠且可正常点击。
2. 主将审核同时显示撤销邀约、拒绝建议、采纳建议：自左向右分别灰棕、暗砖红、棕金；三个按钮同一种装饰轮廓，事件依旧正确执行。
3. 军议邀约首页检查复制战局邀请、再次邀请和关闭。朋友提交内容后再核对审核三按钮。
4. 战绩报告导出海报，海报已保存小弹窗四个按钮要同风格、功能仍分别打开图、文件夹、复制路径、关闭。
5. 战役回放、军帐存档、退出提示、设置和关于游戏的所有按钮不再出现普通纯色矩形。
6. 1920×1080、1280×720、4:3 下检查中文文字没有因为按钮边缘花纹而被遮挡；鼠标悬停、按下和禁用态可辨。
7. 小图标入口和整行可点击的内容列表保留原有呈现，不应被做成小木质按钮。

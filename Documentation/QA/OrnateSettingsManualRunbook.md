# 古风设置面板验收说明

本次改动只涉及设置面板的 UI 外观与调节手势；仍由 `HomeHubUI.cs` 在运行时创建，无须 Unity Inspector 绑定额外图片。视觉通过 `SettingsVisualArt.cs` 中的程序化铜框、刻度、滑块、琴/鼓/日轮矢量纹样绘制；颜色与现有古风按钮统一，参考用户提供的第二张截图但不是逐像素复刻。

## 操作

1. 主菜单右上角设置按钮打开面板，游戏进行中的持续性设置入口同样可用。关闭后再次打开，原有数值继续保留。
2. 背景音乐、音效音量：0–100%，保持 `AudioManager.SetBGMVolume`/`SetEffectsVolume` 行为。
3. 画面亮度：45–100%，保持现有 `ApplyBrightness` 遮罩行为，不虚构0%的可用范围。
4. 使用鼠标或触摸在滑杆全高范围拖动时，显示临时浮动数值；松开后浮标隐藏，右侧百分比始终可见。
5. 左右小箭头每次增减5个百分点，自动钳制到上下限。轨道刻度只有参考功能，**不强制吸附**。
6. 按钮“画面模式：省电 / 标准 / 超清”继续在三个现有 `ApplyQualityPreset` 模式之间循环。悬停、按下时有轻微反馈。

## 必须在 Unity Play Mode 手动检查

- 游戏分辨率 1920×1080、1280×720、窗口自由比例；尤其查看刻度文字、鼓/琴/日轮图案是否相互遮挡。
- 100%或0%时金色填充与雕纹滑块是否正确停在端点；亮度最小45%时标签是否正确。
- 鼠标拖动轨道、滑块；键盘导航；在手机/触屏测试时避免细轨道无法点击。
- BGM音量实际减弱/恢复、音效滑杆不改变BGM独立增益、背景亮度恢复；全局静音按钮独立工作。
- 省电、标准、超清切换和关闭/重开时值不丢失。
- 已接入外部 PNG 图集，程序化贴图仅作为资源缺失时的回退，避免资源导入失败使滑杆丢失。

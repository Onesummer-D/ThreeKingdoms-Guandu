# 主将 ID、战绩海报署名与双端发布验收

## 第一阶段：不依赖服务器的本地 ID

- 启动后若当前浏览器／设备没有已设置的 ID，会先出现**「主将留名」**输入界面，提交以后回主菜单。再次进入同一设备通常直接跳过。
- 接受 3–18 位英文字母、数字、下划线、短横线。例如 `Guandu_07`。不允许尖括号和换行，避免污染海报文本。提交前验证，错误时保留原 ID。
- 主菜单底部显示 `主将 ID：xxx · 修改`，点击可自行修改。新游戏、重新挑战、读取已有进度会检查是否已设置有效 ID。
- 仅写 `PlayerPrefs`，是**本地展示身份，不是账号登录**：不保证 ID 全球唯一；不支持跨浏览器／跨设备同步；清除浏览器站点数据后可能丢失；旧存档并非按玩家 ID 隔离。同设备共享时可更改署名，故不可作为竞赛作弊验证或真正的用户认证。
- 本轮不更改存档格式／参谋 API／后端，也不会把 ID 或昵称自动发送到公网。

## 第二阶段：战绩海报底部落款

- `BattleReportUI.RenderCompleteReport()` 采用 **原报告动态高度 + 固定 160 UI 单位签名区**，署名显示 `主将 ID：xxx`，左侧附项目名。
- 只在**导出 PNG**里添加签名，不改变原本的战绩报告滚动视图，也不与最后一张共谋回声卡片重叠。
- **二维码是可选项**：目前没有正式游戏入口 URL，故**不会输出二维码假图**。上线后把包含正式、稳定 HTTPS 落地页地址的二维码保存为 `Assets/Resources/BattleReport/GameEntryQR.png`，在 Unity 里设为 Sprite (2D and UI)，并确认二维码本身包含完整白边留白（Quiet Zone）。或者在 `BattleReportUI.gameEntryQrSprite` 中指定 Sprite。新的图片在编译后会自动出现在海报右下角。
- 二维码建议指向稳定的 `/play` 落地页，而不是某次临时测试部署：落地页可根据 PC/移动设备分别推荐网页试玩、安卓包或 iOS 版本，从而不因版本变化让海报报废。
- 上线前务必用真实手机扫描**微信、系统相机、浏览器**测试；分享图片时验证 QQ/微信平台压缩后仍可识读。
- **注意 WebGL 下载**：当前 `CapturePoster` 仍使用桌面文件系统 `MyPictures` / `Process.Start`；浏览器上的实际图片下载需要单独引入 JavaScript 插件 + 浏览器 Blob 下载，不能把当前 Windows 保存成功当成 WebGL 保存成功。

## Unity 2022.3 双端计划

当前 `ProjectSettings/ProjectVersion.txt` 表示 Unity `2022.3.62f3c1`。此版本能分别构建 Windows 与 Android/iOS（需要对应 Build Support），也能构建面向桌面的 WebGL；但 Unity 2022 WebGL 对移动浏览器不提供正式支持，不能保证 iOS Safari / Android Chrome 直接打开 Unity WebGL 内容时性能与输入可靠。

**建议分阶段：**

1. PC 网页 WebGL 先上线：完成运行、服务器 HTTPS、静态资源压缩、加载进度/缓存测试。若 Windows PC 原生版本也需要，使用 Windows Build Support。
2. 手机端先确认是 **手机浏览器扫码即玩**，还是 **下载 Android/iOS 原生包**。如果要一个网址两端都在浏览器玩，先单独建分支评估升级 Unity 6，按 Unity 6 官方移动 WebGL 兼容性要求实测；不要直接迁移线上主分支。
3. UI 适配：原游戏以 1920×1080 横屏为参考。使用 Canvas Scaler 的 Scale With Screen Size + 锚点 + Safe Area，在手机横屏设计独立字体、按钮间距与布局；手指目标建议至少约 44–48 CSS px／等效物理大小，尤其资源栏、史官悬浮入口、设置、军议按钮等。部分窗口不能只靠缩放，需要折叠或新布局。
4. 输入适配：鼠标 hover 不可作为唯一交互；支持触摸点击、滚动、软键盘、WebGL 中文文本输入，并避免快捷键与输入焦点冲突。
5. 性能与 API：高分辨率背景、音效和贴图压缩，加载耗时与内存、HTTP API CORS / HTTPS、手机外链与下载交互要逐项测试。

## Unity Play Mode 验收

- 清除测试机 `Guandu.PlayerDisplayId.v1` 相关 PlayerPrefs 后首次启动：出现「主将留名」，输入框可见白色插入光标，非法 ID 不保存，确认后主菜单可交互。
- 已有 ID 时再次启动自动记住；主菜单「修改」能改 ID，旧存档不损坏。
- 设 ID 后开始新一局／读取已有存档；无 ID 时通过游戏入口无法绕过设置。
- 结局打开战绩报告，导出 PNG，验证最末的**共谋回声下方**有署名落款、不遮挡图表/内容；本机 ID 与 PNG 一致。
- 尚未配置 QR 时不出现无法扫描的占位二维码。未来配置正式 Sprite 后检查二维码尺寸、留白及手机扫码。
- Windows 桌面保存功能与 WebGL 浏览器下载是两个独立验收项，不要以桌面测试替代手机/网页测试。

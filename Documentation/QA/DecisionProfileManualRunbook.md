# 战绩画像 Unity 验收

1. 走两个以上关键决策节点，战绩报告显示“本局决策倾向 ·（稳慎／奇谋／果决／兼采并用）”及独立“谋议方式”。查看卡片的行为依据应是本局做过的动作，不得出现没有选择的路线。
2. 单一关键决策、或所有记录均没有有效行为映射时应是“尚待观察”，而不是凭选项中的“奇袭”“采纳”字眼分类。
3. 真人参谋建议一个选项：主将点击“采纳建议”后必须**真正选中同一节点同一选项**才显示“纳谏践行”；只审核却没有按建议操作，不得显示“践行”。
4. 主将拒绝建议而最终战局成功，应显示中性“审议自决”；失败也不改变谋议标签，不使用“固执／错误”。
5. 未邀请真人参谋但剧情中采纳荀彧守官渡的劝谏，可以显示“纳谏践行”，但说明须明确是剧情人物的意见。
6. 本局没有真实参谋审核或剧情中可核验的劝谏记录，则显示“尚无军议记录”，不武断描述为独立筹谋。
7. 原有“四项资源趋势”的“查看详情”仍可打开完整折线图。这里的兵力/粮草实际差值须和决策前后快照一致，不能拿后续整局跌幅冒充单次决策影响。
8. 完成不同小游戏及结局后，“战局记录”按存档实际胜负/结局显示，不反向改判“用兵风格”与“谋议方式”。
9. 检查老存档重开报告、新开局、导出 PNG 长海报是否错行或溢出，尤其新的决策卡片比原来高。

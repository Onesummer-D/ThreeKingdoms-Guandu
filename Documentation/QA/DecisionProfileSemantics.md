# 《官渡之战》战绩报告：行为证据型决策画像 v1（文案组审校稿）

## 实现方式（不调用 DeepSeek）
`Assets/Resources/BattleReport/DecisionBehaviors.json` 为8个有意义的剧情选项节点共19种选项绑定独立语义。以 `nodeId + optionIndex + nextNodeId` 对照 `RunHistoryData.decisions`；**完全不靠 optionText 字符串判断性格**。如文案组修改选项字句而不改实际行动，得出的类型不变。若编辑剧情选项顺序或分支去向，须同步映射，不得默默沿用旧标注。

卡片显示“用兵风格”和“谋议方式”两个维度。前者只根据真实被选中的动作标签分类，后者先判断是否有受邀参谋真实审核记录，再判断有没有在同一节点选中对应选项。如果没有真人参谋记录，再参考剧情里真正采纳／拒绝荀彧劝守的决策。**认可建议 ≠ 执行建议；拒绝建议 ≠ 决策失败。**

资源增减从 `DecisionRecordData.before/after` 读取实际差值，仅作为证据文字，不参与战略风格评分。小游戏与结局只作为独立战果记录，不倒推性格。“四项资源趋势 → 查看详情”继续承担完整资源变化可视化，因此**不要**在本卡片增加“数据可追溯”等空泛文案或复制第二张资源图。

## 需要审校的分类名称（由技术端写稿，文案组只需看是否妥当）

| 维度 | 名称 | 适用条件及推荐语气 |
|---|---|---|
| 用兵风格 | 稳慎 | 优先固守、回援、保全后方；不等于怯战 |
| 用兵风格 | 奇谋 | 用地道、设伏、器械破敌或变化打击目标 |
| 用兵风格 | 果决 | 亲征、集中兵力、快速强硬执行 |
| 用兵风格 | 兼采并用 | 多类真实用兵记录并列，没有突出主导 |
| 用兵风格 | 尚待观察 | 有效行动记录不足，避免强行性格结论 |
| 谋议方式 | 纳谏践行 | 真人参谋建议“已认可”且在对应节点“实际执行”，或确实采纳了荀彧劝守 |
| 谋议方式 | 审议自决 | 已收到/审核意见，最终选择其他路线；**中性，不用固执、刚愎自用、不听劝** |
| 谋议方式 | 议而未决 | 有已审核意见，但未取得该节点的实际决策记录 |
| 谋议方式 | 尚无军议记录 | 没有可核验的建议/采纳记录；**不推断玩家是独立筹谋还是不善纳谏** |

说明：旧版“纳谏”与“奇谋”互相争名次并不合理。新版将其移到第二维，容许“奇谋 + 纳谏践行”“稳慎 + 审议自决”等组合，不涉及道德评判。

## 已实现的解释文案（请文案组审校，非新增写作任务）

**用兵风格**

- 稳慎：本局多次优先考虑守住阵地、保障退路与控制战局风险。
- 奇谋：本局多次选择器械、迂回或改变交锋方式，以寻找战局突破口。
- 果决：本局多次在关键时刻迅速主动部署，集中力量付诸行动。
- 兼采并用：本局采用过不同用兵方式，尚无单一风格明显占优。
- 尚待观察：本局尚无足够的关键战术选择，不作固定用兵风格判断。

**谋议方式**

- 纳谏践行：有参谋意见经主将认可，并与本局实际选择相符。（若只有剧情中荀彧的劝守记录，将明确写成采纳荀彧意见，不冒称有真人参谋。）
- 审议自决：主将听取了参谋建议，最终依自己的判断作出选择；这不是对决策好坏的评价。
- 议而未决：参谋已提出建议，但尚无对应决策记录，不推断建议是否得到执行。
- 尚无军议记录：本局没有可核验的谋议审核记录，不据此评判主将是否善纳人言。

**实际行为依据**：不是固定范文。只有被实际选择的 `nodeId/optionIndex` 才解锁“第X幕 · 具体动作”，若有可信 before/after 快照则在后面加 “实际：兵力-10、粮草-5” 等动态变化。真人参谋证据从 `advisorEchoes` 审核及 `decisions` 对照而来。小游戏胜负和结局另外列为“战局记录”，与倾向评分无关。

## 对需要特别保护的场景的写法

**主将邀请了朋友，朋友建议回防，主将未采纳而自行率军，最后取胜：**

- 用兵风格按**本局实际各次用兵行为**统计，不由“是否听从”或“最后赢没赢”决定。
- 谋议方式：**审议自决**。
- 行为依据：参谋「某某」参与军议，主将最终另作决断。
- 战局记录：本局结局：实际已抵达的结局名称。
- **不要写**“主将拒绝良言却侥幸获胜”“不听劝告”“性格固执”。同样也不应因为赢了就断言“参谋意见必然错误”。

## 边界及后续完善

- v1 是**按剧情设计者手工标注的战术行为画像**，不能声称是有统计学效度的性格测量。
- 8个关键或补充节点共19条映射是第一批，其他非关键情节、纯对白节点不会虚构加分；1条有效战术选择不足以给出稳定类型；第一幕的纯「确认」节点（1004）不会计入分析，政治性质的焚毁／保留书信（500214）虽被记录但不强行贴战术标签，等分则“兼采并用”。
- 旧存档已有 nodeId、optionIndex、nextNodeId、选择前后资源与参谋审核记录，运行时可重新计算，无须改存档格式或服务器。缺乏真实动作证据时显示“不足”，不回退到关键词。
- 若调整选项的结构（而非单纯润色文本），必须同步修改行为映射，并运行 CI。实际 Unity Play Mode、长海报排版与手机端用语还需实机核对。

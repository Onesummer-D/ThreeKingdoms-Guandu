# 音效与常驻入口验收（Unity Game 视图手测）

## 检查前
- 建议先记录当前的“背景音乐 / 音效音量”设置值。如果之前已经修改并保存过音量，旧设置会被保留；新默认值（BGM 75%、音效 90%）仅对未保存过设置的设备生效。
- 在 Windows Unity Editor 实机耳机/扬声器下测试，不依赖源码静态检查判断“声音是否听得见”。
- 从主界面开始一局，沿首幕节点 100101 → 100104 → 100105 推进。

## 首幕放箭
1. 到达 100104（“强弓硬弩破空……矢下如雨”）时，应**只在进入这个节点时**听见“箭矢破空音.ogg”，不需要点任何按钮才能触发。
2. 箭声开始时背景音乐快速降低；箭声结束后背景音乐平滑恢复，不能抽搐、瞬间切回或者压过箭声。
3. 节点 100104 快速连点进入后续节点，确认不存在卡住的 BGM 降音、重复箭声或 BGM 意外停止。
4. 在 500201 后期剧情节点继续验证原有箭矢素材绑定没有失效。

## 音量调节与混音
1. 全新设置（没有旧 PlayerPrefs）时，初始背景音乐约 75%，音效约 90%。旧玩家自定义设置不能被静默重置。
2. 两个滑块分别设为 0%、50%、80%、100%，核对音效与 BGM 相互独立；**音乐设为 0 时音效仍能响**，音效设为 0 时不得有箭声。
3. 连续触发点击、数值变化、提示、成就、小游戏等音效，听感需足够突出但无爆音；若原始录音响度仍明显偏低，需要音频制作组对素材做响度标准化（不要无界放大数字音量）。
4. 在小游戏压低背景音时调整 BGM 滑块，返回剧情后正常恢复用户所设音量，不得被小游戏状态永久锁在很低声。
5. 静音后 BGM、剧情音效和 UI 点击全部静音，再按喇叭图标恢复原来的滑块设置。

## 常驻右上角设置 / 静音
1. 主界面、第一幕普通对话、背景介绍、四类小游戏、特殊演出、任意结局界面都能在**右上角**看到齿轮和喇叭，并可点击。
2. 齿轮打开原来的设置弹窗；修改背景音乐/音效后关闭重开，数值与实际音量保持一致。
3. 静音图标状态与真实声音一致；不出现主界面和剧情界面双份图标。
4. 1920×1080、1280×720、1024×768 检查图标边缘、遮挡与点击区域。

## 左侧问史官
1. 进入本局后问史官图标位于**左侧头像框下方**；不能出现在右侧资源条下面。主界面无活动对局时不显示史官入口。
2. 在首幕普通对话、背景介绍、小游戏暂停界面和结局界面，都能点击史官打开聊天，关闭后原来的 UI 交互恢复。
3. 史官打开时游戏暂停、保存本局聊天；从结束界面重新开局应清空上局对话。返回主页时不得看到上局史官入口。
4. 窗口打开后输入法拼音、编辑光标、发送/来源展开等功能不能退化（已在 PR #1 修复）。
5. 三档分辨率核对史官按钮不盖住人物头像、剧情回顾按钮或主菜单。

## 本轮：箭雨节奏与走格子胜负停留

1. 在首幕节点 **100104** 进入“矢下如雨”的画面，应听到约两秒内**8次快慢错落的箭矢破空声**，BGM 在整个连续段压低，最后平滑恢复。不能只响一次。
2. 在 **100104** 听到两三下后立即点进 **100105**，剩余队列应停止，避免下一幕仍连续发箭；正在衰减的最后一声允许自然结束。
3. IF6 节点 **500416** 的“万箭齐发”也应为同一连续箭雨。普通零星箭矢节点如 100605 和 500205 仍保留单次效果，避免每次射箭都演成齐射。
4. 走格子游戏**胜利**时：玩家停留在最后一格，显示“胜利！成功奇袭乌巢！”；音效《达成成就》长约 **4.6 秒**，应当在停留期间完整播放，约音效结束后再跳转后续剧情。
5. 走格子**失败**时：玩家停留在被发现的最后一格，显示“失败！被敌军发现！”；报警音长约 **1.8 秒**，应只响一次，播完再转入失败分支并扣除20兵力。
6. 结果停留时继续按 WASD、点击格子或确认按钮，不能额外移动、重复播放结果声或重复跳转；重新玩一局后可正常选起点。
7. 若在结果停留期间打开史官窗口暂停游戏，结果画面不应该在窗口后方切换剧情；关闭史官后继续计时。
8. 将音效设置为0%或全局静音再结束一次小游戏，应该可以在短暂显示结果后继续，不必无声等待完整的4.6秒。
9. **特别提醒**：当前 `箭矢破空音.ogg` 源素材本身只有约0.4秒，平均响度不高，且前导低电平检测异常。代码改为多次错落播放并降低 BGM，但若真实试听仍不像箭雨，需要换/重新制作更厚实的多层箭声，不应只继续调增益。

## 自动检查
- `node Documentation/QA/AudioHudStaticChecks.js` 校验资源引用、代码路径和常驻层级。
- `node Documentation/QA/NarrativeAudioAuditChecks.js` 校验所有剧情节点的音效引用与关键场景是否正确绑定。全部补音 / 缺素材待办见 `NarrativeAudioAudit.md`。
- 该检查**不是** Unity 编译 / Play Mode 或真实声学听感测试。

## 文件与代码交付约定

- 新素材放置 `server/public-advisor/public/assets/`，不放 Unity 的 `Assets/`：这是单独的 H5 页面。
- 如有 PSD/Figma 源文件，可另行存档；实际游戏发布用 PNG/WebP（照片/大背景 WebP；透明边框、徽章、印章 PNG）。
- 不在静态图中写：主将 ID、剧情、选择、资源值、时间、倒计时、固定按钮文案、服务器网址。所有这些必须可以随 API 数据变化。
- 避免水印和未获许可的版权素材。保存每件资产来源、作者及可商用授权证据，方便比赛/正式发布。
- **server.js 当前对 /assets 有显式文件白名单。** 美术上传后还需同时更新 `assetTypes`、CSS 贴图和移动端实机测试，不能只上传图片就宣称可用。
- 交付每张图时请提供你希望使用的显示裁切范围（尤其 9-slice 的边框宽度和安全区）。在 360/390/430px 视口分别测试文字溢出和控件触摸操作。

## 核心游戏机制保留

- 已走剧情由当前 Unity 实际历史回顾字段传来；网页不添加未发生事实。
- 不提前展示三个方案的兵力/粮草/计策/风险收益。这里只显示**当前**资源状态。
- 当前服务**只接受一条参谋建议**，不能把提交成功称为“主将已采纳”。
- 真实有效期来自服务器 `expiresAt`，没有虚构倒计时。
- 页面优先回答“主将当前为什么困难／在问什么／我要选什么”，宣传按钮次要且上线 URL 未设置时隐藏。

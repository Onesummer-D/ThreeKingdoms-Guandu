# 阶段四：文化信息扩充与邀约式共创

日期：2026-09-01

状态：核心功能完成，4D 静态验收完成；Unity 实机回归待执行

## 2026-09-11 更新：4C 本机离线参谋建议闭环第一增量

根据最新反馈，存档确认提示已移除末尾句号。阶段四 4C 开始从“复制战局文字”进入可操作的本机接力：军议邀约卡现在可生成当前快照接力码，进入“应邀加入”后填写昵称、选择当前选项即可提交，理由为可选项，主将可在审核面板采纳、拒绝或撤销。

该流程只写入运行时会话和本局战绩的“共谋回声”，不会自动点击剧情选项，也不会重复扣除资源或改变既有结局判定。新局、读档、返回主菜单和重置都会清除旧邀约，不宣称跨设备联网。

本轮已通过定向 UI 编译、36 条章节检查、存档/首页设置/运行日志/战绩报告和邀约闭环契约检查；Unity Game 视图烟测与五锚点、终局回归留在下一停点。

## 2026-09-11 追加：应邀输入框复用与可选理由

修复第二次打开“应邀加入”时昵称、理由输入框无法获得焦点的问题，重开面板会清理旧选中对象并恢复输入框的可交互状态。理由现在允许留空，只需昵称和建议；缺少这两项时提示改为“请填写昵称并选择建议”，不带句号。旧的本机/离线说明文案不再显示。

## 2026-09-04 更新（以下旧版短码方案已暂停）

用户实机反馈表明，邀请卡文本截断且复制短码没有可加入入口。此前“任务二首批完成”仅指代码存在，不应当作邀约功能验收通过。

本次代码改为可滚动的邀请正文、固定标题和操作区；去掉无用短码，复制完整战局文本供玩家人工转发。页面明确当前尚未实现手机加入和自动回传，不能称为完整邀约式共创。

开始游戏前新增曹操主将身份说明，可返回或确认出征。未新增许攸/袁绍独立路线。修复四位锚点被第一幕宽泛范围误判，章节卡高亮也使用同一分类入口。

已安排存档、关于游戏/设置、战绩报告、PNG 海报、手机参谋与文化深化，详见《阶段四扩展落地方案》。它们并未在本次全部实现。

当前验证：目标脚本独立编译已通过；生产幕次分类函数的 36 项检查通过。Unity 画面、按钮点击和剪贴板实机检查尚待执行，不宣称完成整机或 Windows 构建验收。新增可重跑的 `Documentation/QA/VerifyPhase4.ps1` 和 4A 实机清单。

## 阶段定位

阶段四承接阶段三已经完成的剧情回顾与史官注，把项目从“玩家独自经历并复盘”推进到“玩家可以邀请他人共同提出下一步”。当前过渡版是可复制的战局文字，真实手机加入与建议回传仍在后续批次。

## 任务一：邀约会话契约（已完成）

历史版本曾设计 `InviteSessionState` 与本地短码；该短码没有加入服务，已在 2026-09-04 停用，不作为跨设备能力宣传。

邀约状态只存在运行时对象中，主玩家确认后只生成“共谋回声”衍生内容，不写入对白节点、资源数值、结局判定或 ScriptableObject。取消、关闭、返回主菜单和重新开始都会清理邀约会话。

## 任务二：军议邀约快照卡（首批已完成）

新增 `Assets/Scripts/UI/InviteCoCreationUI.cs`，由 `FinalUIManager` 在运行时自动创建。当前“军议邀约”只在五个实时决策锚点出现，避免把入口塞进剧情回顾或提前泄露内容。

点击入口后可看到“战局快照”：当前幕次、已走剧情、已选路线、当前问题/选项和兵力/粮草/计策/风险四项资源（均显示 /100）。邀请卡沿用官渡回顾的深色面板、暖金色标题和中文字体，并提供“复制战局邀请”按钮，方便人工转发。

本停点暂不实现应邀加入和共谋结果，避免把未验收的交互一次性叠加。下一步将在同一张快照卡上增加“应邀加入”入口，完成邀请码校验、策略建议和主玩家确认/拒绝。

## 2026-09-11 追加：二次打开输入框恢复

应邀页在重复打开时先重新激活父面板并刷新画布，再重置接力码、昵称和理由三个 TMP 输入框；输入框显式绑定背景图、可交互且非只读。关闭邀约/回顾时清理 EventSystem 选中项，避免旧焦点导致第二次无法输入。理由可留空，提交提示改为“请填写昵称并选择建议”。

状态机同时将 `null` 理由规范化为空字符串，复制邀请文案也明确“理由可选”，避免非 UI 调用或人工转发时产生必填误解。

共谋回声卡的理由文本现在从“理由：”另起一行；战绩报告曹操头像旁的结局摘要改为水平居中，并已加入报告契约检查。

为阶段回归补充五个真实决策锚点的状态机循环检查，覆盖不同选项数量下的空理由提交、采纳和会话重置；Unity Game 视图烟测仍是 4C 收口前的唯一未完成项。
